چطور کار می‌کند

یک برج. همهٔ Claudeها.

Claude Code، Claude Desktop و claude.ai همه از یک دروازهٔ کوچک روی مک شما به Anthropic می‌رسند. این دروازه فقط وقتی باز می‌شود که برج کشورتان را تأیید کرده باشد و مسیر باز باشد. هر چیز دیگری که می‌بینید از روی همین دستگاه خوانده می‌شود.

صادق، از پایه

حقیقت را به شما می‌گوید.

در تردید، بسته

یک درخواست Claude فقط وقتی رد می‌شود که داخل کشورتان و روی مسیری قابل‌استفاده تأیید شده باشید. نامطمئن، کش‌شده یا آفلاین یعنی نگه‌داشته. هیچ راه دررویی برای عبور وجود ندارد.

در انتظار، هرگز شکست‌خورده

نگه داشتن با 503 و Retry-After جواب می‌دهد، هرگز با 403؛ پس Claude در چرخندهٔ خودش منتظر می‌ماند و همان نوبت ادامه پیدا می‌کند.

خاموش کردن، دو بار بله

خاموش کردن گارد یا خروج به شما می‌گوید همین حالا چند ایجنت در حال کارند و بعد دوباره می‌پرسد. روشن کردنش یک ضربه است.

توکن شما مال خودتان

مصرف از /usage خود Claude می‌آید. پراکسی نام میزبان را می‌بیند و آنچه می‌فرستید را هرگز رمزگشایی نمی‌کند.

مشاهده، هرگز هدایت

وضعیت از هوک‌های خود Claude Code می‌آید. Tower به همهٔ آن‌ها یک 200 خالی جواب می‌دهد و هرگز در یک session تایپ نمی‌کند.

بدون درخواست مجوز

هرگز داخل Photos، Documents، Desktop یا Downloads را نمی‌خواند و رمز نمی‌خواهد، حتی برای بیدار نگه داشتن با درِ بسته.

Tower را نصب کنید.

یک خط. بدون رمز، بدون دیوار Gatekeeper، بدون کشیدن و رها کردن. در اولین اجرا Claude را از گارد عبور می‌دهد، و همین خط به‌روزش هم می‌کند.

$curl -fsSL https://ghhrmnzdh.github.io/tower/install.sh | sh

Tower را در Applications نصب می‌کند، tower را به PATH اضافه می‌کند و اجرایش می‌کند. فایلی که با curl گرفته شود هرگز قرنطینه نمی‌شود، پس macOS جلویش را نمی‌گیرد. اول اسکریپت را بخوانید؛ غریزهٔ درستی است.

$curl -fLO https://github.com/ghhrmnzdh/tower/releases/latest/download/tower_all.deb
$sudo apt install ./tower_all.deb
$tower-tray

نسخهٔ کامیونیتی برای Ubuntu و Debian: رادار در نوار بالا، داشبورد (tower) و daemon، همه در یک بسته. نصب چیزی را اجرا نمی‌کند؛ باز کردن یکی از رابط‌ها اجرایش می‌کند. GNOME رادار را از طریق افزونهٔ appindicator نشان می‌دهد.

>git clone https://github.com/ghhrmnzdh/tower
>python tower\src\tower-tui.py

پیش‌نمایش کامیونیتی، هنوز روی یک کامپیوتر واقعی Windows اجرا نشده. یا روی Tower (Terminal).cmd دوبار کلیک کنید تا Python را خودش پیدا کند. لطفاً بگویید به چه مشکلی خوردید.

نه. مصرف پلن از دستور خود Claude Code یعنی claude -p /usage خوانده می‌شود؛ ورود را خود Claude انجام می‌دهد و Tower هیچ توکنی را نمی‌خواند. پراکسی ترافیک HTTPS را با CONNECT تونل می‌کند: فقط نام میزبان‌ها را می‌بیند و آنچه می‌فرستید را هرگز رمزگشایی نمی‌کند.

Tower چطور Claude Code را در یک کشور نگه می‌دارد؟

یک پراکسی محلی کوچک اجرا می‌کند و Claude Code را از طریق بخش env در ~/.claude/settings.json به آن وصل می‌کند، هرگز از طریق shell شما. یک درخواست Claude فقط وقتی رد می‌شود که تأیید شده باشد داخل کشورتان هستید و مسیری قابل‌استفاده تا Anthropic دارید. در غیر این صورت چند لحظه نگه داشته می‌شود و با 503 و Retry-After جواب می‌گیرد؛ پس Claude در چرخندهٔ تلاش دوبارهٔ خودش منتظر می‌ماند و خودش ادامه می‌دهد.

Tower از کجا می‌داند هر ایجنت چه می‌کند؟

از طریق هوک‌های خود Claude Code. Tower کنار تنظیم مسیردهی خودش در settings.json چند هوک HTTP فقط برای مشاهده اضافه می‌کند، به هوک‌های شما دست نمی‌زند و در هر خروج هوک‌های خودش را برمی‌دارد. این هوک‌ها همیشه یک 200 خالی جواب می‌گیرند: Tower هرگز جلوی چیزی را نمی‌گیرد، به جای ایجنت تصمیم نمی‌گیرد و چیزی تایپ نمی‌کند.

اگر Tower بسته شود یا از کار بیفتد چه می‌شود؟

هنگام خروج، اول پراکسی از settings.json برداشته می‌شود تا sessionهای جدید Claude مستقیم وصل شوند. چت‌هایی که از قبل به پراکسی وصل‌اند از طریق یک رله‌ٔ عبوری تا وقتی بسته شوند کار می‌کنند، و Tower بعدی همان پورت را پس می‌گیرد. خاموش کردن گارد یا خروج، دو بار تأیید می‌شود.

Tower رایگان است؟ روی Linux و Windows اجرا می‌شود؟

Tower رایگان و متن‌باز است. روی macOS 14 یا جدیدتر (Apple Silicon) یک اپ نوار منو، یک داشبورد بومی و یک داشبورد ترمینال است. Linux و Windows نسخه‌های کامیونیتی هستند. روی Ubuntu 22.04 تا 26.04 و Debian، یک بستهٔ deb شامل daemon، داشبورد ترمینال و یک رادار در نوار بالاست و در هر نسخه داخل CI نصب و اجرا می‌شود. روی Windows 10/11، daemon و داشبورد ترمینال یک پیش‌نمایش‌اند: نوشته و بازبینی شده‌اند، اما هنوز روی یک کامپیوتر واقعی Windows اجرا نشده‌اند.
